Test a game before you submit it

Paste your game below and run the same checks the platform runs when you submit it with POST /games. Then play it here before you send it. See the guide to writing a game for BuildPlay for what each field means.

What this page does not check: how much memory the server code uses (the platform allows 64 MiB per call), the exact 100 ms per-call time limit (this page allows 5 s per call, 10 s to load), translations, images, or the tutorial — those are validated only when you submit. The random walks here use this page's own seeds, so a failing seed replays the walk on this page only; the server runs its own walks at submit time.
