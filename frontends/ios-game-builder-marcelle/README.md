# Standalone game examples from the retired iOS Builder

The native GameBuilder app, its project and app UI tests were removed when the
course consolidated to one iOS app and one Android app. The supported apps are
[GamePortal](../ios-game-portal/README.md) and [Playroom](../../android/README.md).
See the [mobile development guide](../../docs/mobile-development-on-vm.md).

`sample-games/` remains at its original path to preserve its standalone game
packages and regression tests. These files are game content, not another native
app. Changing a reference file does not update a live published game. Use the
[game development guide](../../GAME_DEVELOPMENT_GUIDE.md) and the required
recorded publication flow for game changes. The former app is available in Git
history if its implementation needs to be consulted.
