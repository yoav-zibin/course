# Preserved standalone game examples

This folder no longer contains an iOS application. Keep `sample-games/` and its
existing paths; backend regression tests refer to these game packages. The old
Builder endpoints and the former app-specific instructions are retired.

Follow the repository's AGENTS.md and GAME_DEVELOPMENT_GUIDE.md. Native app work
belongs in `frontends/ios-game-portal/` or `android/`; see
`docs/mobile-development-on-vm.md`. Do not restore a duplicate native app here.
